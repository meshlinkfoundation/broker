# Security

If you discover a security vulnerability in this project, please report it responsibly.

**Do not** open a public GitHub issue for security-sensitive bugs.

Instead, report it by email to the maintainers (contact details to be added). Include a clear description and steps to reproduce if possible. We will respond as soon as we can and will work with you on a fix and disclosure timeline.

We appreciate your help in keeping meshlink and its users safe.
