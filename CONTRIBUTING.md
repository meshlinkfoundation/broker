# Contributing to broker

Contributions are welcome. A few guidelines:

- **Issues**: Open an issue for bugs, feature ideas, or questions. Check existing issues first.
- **Pull requests**: Prefer small, focused PRs. One logical change per PR is easier to review.
- **Breaking changes**: Don’t introduce breaking changes without prior discussion (e.g. in an issue).
- **Scope**: This repo is the reference implementation of the MeshLink broker captive portal. See the [Scope & Stability](README.md#scope--stability) section in the README.

Thank you for contributing.
